# 📚 AI-Powered Library Management System

A modern and responsive **Library Management System** built using modern web technologies with a clean UI, fast performance, and smart management features for both students and employees.

---

# 🚀 Features

## 👨‍🎓 Student Features
- View all available books
- Search books instantly
- Filter books by category
- Responsive user interface
- Dark/Light modern design

## 👨‍💼 Employee/Admin Features
- Add new books
- Update existing books
- Delete books
- Manage book availability
- Real-time database updates

---
